# 지성 오락실

직접 만든 웹게임과 도구를 오락기 한 줄로 보여 주고, 고르면 각 게임 페이지로 연결하는 포탈입니다.
게임은 각자 자기 저장소·페이지에서 따로 업데이트되고, 이 포탈은 **링크만** 가지고 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 포탈 화면 (오락기 줄, 안내판, 도구, 링크 설정 화면) |
| `links.json` | 게임·도구별 연결 주소. 모든 방문자에게 적용되는 기준값 |

## 링크 바꾸기

`links.json`에서 해당 줄의 주소만 고치면 됩니다. 빠진 항목은 포탈에서 "연결되지 않음"으로 표시되고, 눌러도 열리지 않습니다.

| 키 | 항목 |
| --- | --- |
| `kart` | 볼트러시 GP |
| `rts` | 심플크래프트 |
| `fort` | 포탄 언덕 |
| `volt` | 변신 로봇 볼트 |
| `track` | 연타 육상대회 |
| `mage` | 천 년의 여행 수첩 |
| `brick` | 문 너머 브릭월드 |
| `board` | 로봇 배움 한바퀴 |
| `ai` | 질문 한 줄의 여행 |
| `cafe` | 무인카페 동선 시뮬레이터 |
| `news` | 글로벌 이슈 지도 |

포탈의 **링크 설정** 화면에서 고친 내용은 그 브라우저에만 저장됩니다. 모두에게 반영하려면 설정 화면의
**links.json 내용 복사**로 복사해 이 파일에 붙여 넣으세요.

## 배포

빌드 과정이 없는 정적 페이지입니다. GitHub Pages나 Netlify에 저장소를 연결하면 그대로 동작합니다
(`links.json`을 불러오기 때문에 파일을 더블클릭해 여는 방식에서는 링크가 비어 보일 수 있습니다).
